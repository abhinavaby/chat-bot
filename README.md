# Chatbot Website 🤖

A simple static chatbot demo built with HTML, CSS, and JavaScript.

## 🚀 What’s included

- `index.html` — page structure and chat layout
- `styles.css` — UI styling for the chat interface
- `app.js` — bot logic, chat messages, and keyword suggestion blocks

## 💡 Features

- Clickable keyword suggestion blocks for quick chat prompts
- Interactive chat window with user and bot messages
- Basic rule-based responses for greetings, help, time, and more
- Dark UI with polished cards and responsive layout

## ▶️ How to use

1. Open `index.html` in your browser.
2. Type a message into the input field or click a keyword block.
3. Press **Send** or hit **Enter**.

## 🛠️ Customize

- Add or update reply rules in `app.js`
- Change the theme in `styles.css`
- Extend the bot with more advanced logic or API integration

## 📌 Notes

This is a static demo and does not require a server. It runs entirely in the browser.
